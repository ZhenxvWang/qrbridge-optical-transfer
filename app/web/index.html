使用说明

两台电脑，一条视觉链路

从统信 UOS 传到 Windows

  1. 在 UOS 上打开码桥，选择“发送文件”，选中文件并开始播放。
  2. 在 Windows 上打开码桥，选择“接收文件”，点击“开启摄像头扫描”。
  3. 把 Windows 摄像头对准 UOS 屏幕上的四宫格二维码，保持 20–60 cm。
  4. 进度到 100% 且校验通过后，点击“保存文件”。

从 Windows 传到统信 UOS

  1. 在 Windows 上选择文件并播放二维码。
  2. 在 UOS 上开启摄像头扫描。
  3. 若 UOS 主机没有摄像头，可改用带摄像头的 Windows 笔记本作为接收端，方向反过来即可。

提高识别率

  • 把发送端屏幕亮度调到最高，关闭夜间模式、护眼模式和自动亮度。
  • 使用“全屏”显示四宫格，避免反光和摩尔纹；镜头与屏幕尽量垂直。
  • 先试“均衡 + 4 路 + 5 帧/秒”。识别慢就降到“稳定”或“单码”。
  • 摄像头请选 720p 或更高；关闭会议软件、相机应用等占用摄像头的程序。
  • 接收端不要离屏幕太近，太近会无法对焦；也不要太远导致二维码太小。

常见问题

浏览器没有弹出摄像头授权？
点击地址栏左侧的权限图标，把摄像头改为“允许”，然后刷新页面。统信 UOS 还需在“控制中心 → 隐私 → 摄像头”中确认浏览器有权限。
提示“当前浏览器不支持摄像头”？
请使用系统自带浏览器或 Chromium 80 以上版本打开本页面。不要使用 IE 或很旧的浏览器内核。
一直卡在 99%？
发送端会循环播放所有分片，通常再等一轮即可补齐。也可以点击“复制缺失分片”查看缺哪些帧；若长期缺失，降低档位或帧率后重新发送。
文件太大？
二维码是低速视觉通道，建议单文件不超过 1 MB。程序会先用 gzip 压缩；文本/JSON/日志通常能明显变小，docx/zip/图片本身已压缩则效果有限。上限为 8 MB。
UOS 提示 deb 没有有效数字签名？
统信安装器要求统信开发者证书签名，第三方无法生成合法签名。请改用便携包里的 install-user.sh 用户级安装，不需要 root 和开发者模式；详见发布包中的 SIGNING.md。
程序没有自动打开浏览器？
在 UOS 终端运行 qrbridge 查看地址；日志在 ~/.cache/qrbridge/qrbridge.log。Windows 日志在 %LOCALAPPDATA%\\QRBridge\\qrbridge.log。

隐私与安全

码桥只监听本机回环地址 127.0.0.1，所有页面资源都打包在程序内，不会发起外部网络请求。文件分片只在浏览器内存中处理，接收完成后用 SHA-256 校验完整性。二维码在物理空间可见，请勿在公共场所传输敏感文件。
